# 数学知识图谱数据加载指南

## 当前问题分析

从日志中可以看到，您点击了"加载全图"按钮，系统尝试加载"初中数学"节点的分支数据，但由于Neo4j数据库连接问题，返回了空数据。

## 解决方案

### 方案一：配置真实的Neo4j数据库

如果您有Neo4j数据库，请修改 [`app.py`](app.py) 中的配置：

```python
# Neo4j配置 - 修改为您的实际配置
NEO4J_URI = "bolt://localhost:7687"      # 您的Neo4j地址
NEO4J_USER = "neo4j"                     # 您的用户名  
NEO4J_PASSWORD = "您的密码"              # 您的密码
```

### 方案二：使用模拟数据（推荐用于演示）

我将为您创建一个模拟数据加载功能，让您在没有Neo4j数据库的情况下也能看到图谱效果。

## 使用说明

### 立即体验（推荐）

1. **刷新浏览器**：重新访问 `http://localhost:5000`
2. **点击"加载模拟数据"按钮**：这将加载预定义的初中数学知识图谱数据
3. **交互操作**：
   - 点击图中的节点查看详细信息
   - 使用鼠标拖拽来移动图谱
   - 使用鼠标滚轮来缩放图谱

### 数据加载方式

现在系统支持三种数据加载方式：

1. **模拟数据** - 点击"加载模拟数据"按钮（立即可用）
2. **真实数据** - 点击"加载全图"按钮（需要配置Neo4j数据库）
3. **章节导航** - 在侧边栏选择章节（需要配置Neo4j数据库）

### 模拟数据内容

模拟数据包含：
- **根节点**：初中数学
- **3个章节**：有理数、整式的加减、一元一次方程
- **4个小节**：正数和负数、有理数的加减、单项式等
- **3个知识点**：正数的概念、负数的概念、有理数加法法则

## 下一步

1. **立即体验**：点击"加载模拟数据"查看效果
